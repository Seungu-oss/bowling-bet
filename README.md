# 🎳 볼링 내기 정산

**👉 바로가기: https://seungu-oss.github.io/bowling-bet/**

이름과 점수만 입력하면 게임마다 순위를 매겨 누가 얼마를 주고받는지 계산해 주는 페이지입니다.

## 기능

- **인원·게임 수·게임당 금액 조절**: 인원 2~30명, 게임 1~20게임, 금액은 기본 2,000원이고 직접 바꿀 수 있습니다.
- **1게임은 음료수 게임**: 첫 게임은 정산에서 빠집니다. 설정에서 끌 수 있습니다.
- **정산 방식 선택**: 상위 절반 vs 하위 절반(기본), 전원 1:1 맞대결, 꼴찌가 1등에게, 순위별 차등
- **동점 처리**: 금액이 갈리는 자리에서 동점이 나오면 0원으로 두고 노란색으로 표시합니다. 다음 판 초구로 정한 뒤 **보정** 칸의 +/− 버튼으로 게임당 금액만큼 더하거나 뺍니다.
- **송금 정리**: 누가 누구에게 얼마를 보내면 되는지 최소 횟수로 정리해 줍니다.
- **점수표 캡처**: 이름·점수·정산·평균을 PNG 이미지로 저장하거나 복사할 수 있습니다.
- 빈 칸은 그 게임에 불참한 것으로 처리합니다.
- 입력한 내용은 사용하는 브라우저에만 저장되고, 서버로 전송되지 않습니다.

## 사용법

1. 인원, 게임당 금액, 정산 방식을 고릅니다.
2. 이름과 게임별 점수를 입력합니다. 점수 칸에서 엔터를 누르면 다음 사람으로 넘어갑니다.
3. 아래 **최종 정산**과 **송금 정리**를 확인하고, 필요하면 **결과 텍스트 복사**나 **점수표 캡처**로 공유합니다.

## 수정·배포

`index.html` 파일 하나로 된 정적 페이지입니다. 수정 후 `main` 브랜치에 push하면 GitHub Pages에 자동으로 반영됩니다.
